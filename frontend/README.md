# Веб-интерфейс

Для запуска нужны Node.js 22 и FastAPI на порту 8000. Команды выполняются из каталога `frontend`.

```sh
npm ci
npm run dev
```

Vite открывает приложение на порту 5173 и проксирует запросы к бэкенду. Адрес прокси задаёт `BACKEND_URL`. Продакшен-сборку из `frontend/dist` раздаёт FastAPI.

## Структура

- `src/app` подключает провайдеры, маршруты, общие стили и токены темы.
- `src/pages` содержит точки входа маршрутов. React Router загружает их по мере переходов.
- `src/features` хранит компоненты, CSS Modules, формы, запросы TanStack Query и тесты по функциям приложения.
- `src/shared` содержит клиент OpenAPI, общие элементы интерфейса, сессию, тему, форматирование и адреса страниц.

Внешние импорты проходят через `index.ts` слайса. Границы зависимостей проверяет ESLint.

## Контракт API

После изменения моделей или маршрутов FastAPI выполните из корня репозитория `python scripts/generate_types.py` в окружении бэкенда. Скрипт экспортирует `frontend/openapi.json` и запускает генерацию типов. Для повторной генерации из сохранённой схемы достаточно `npm run gen:api` в каталоге фронтенда.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Vitest использует Testing Library и MSW. Playwright запускает локальную продакшен-сборку и подставляет ответы API для браузерных сценариев.
