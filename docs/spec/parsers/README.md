# Спеки парсеров после пилота RussiaRunning

Список опирается на [ТЗ v1.3, §6](../SPEC.md#6-источники-и-адаптеры) и [пилот #27](https://github.com/czczczt/sports-agent/issues/27). Ссылки и форматы из репозиторной разведки нужно подтвердить при реализации на целевом стенде.

Первым подключаем ПроБЕГ. Эта задача выделяет общий интерфейс запуска и проверяет его на двух разных движках. Остальные адаптеры используют тот же контракт. Timerman, Легков и Pioner Cup сгруппированы по движку RR. Забег.РФ разбит на проверку хронометристов, поскольку брендинг старта сам по себе не определяет движок.

Сбор использует публичные протоколы. Путь получения выбирается по источнику в порядке HTTP, браузерная загрузка, поиск ссылки, ручная загрузка. HTML-рецепт подключается там, где формат укладывается в существующий контракт рецептов. Для фильтрации спортсменов общие правила задаёт ТЗ. Для всех источников сохраняются происхождение результата и стабильные идентификаторы.

Расписание сбора и уведомления относятся к общему конвейеру. После приёмки ручного запуска отдельно включается периодический сбор для источников с подтверждённым обнаружением стартов. Включение расписания требует лимита на домен, непересекающихся запусков одного источника, журнала, повторов и оповещений о сбоях по ТЗ. Интерфейс оператора координируется с [#26](https://github.com/czczczt/sports-agent/issues/26).
