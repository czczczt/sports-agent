# Russialoppet — протоколы и данные для сезонных очков

## Проблема

Для лыжного рейтинга нужны результаты марафонов, возрастные группы и отметка серии.

## Решение

Подключить протоколы Russialoppet и сохранить входные данные для отдельного сезонного расчёта.

## Пользовательские истории

1. Как администратор, я хочу запускать сбор и видеть статус, чтобы обрабатывать старты без отдельных скриптов.
2. Как модератор, я хочу видеть источник и неоднозначные совпадения, чтобы подтверждать только корректные привязки.
3. Как пользователь рейтинга, я хочу видеть согласованные результаты, чтобы сбой источника не менял мой балл.
4. Как разработчик, я хочу воспроизвести разбор на сохранённом образце, чтобы проверять изменения без сети.

## Решения по реализации

- Различать марафон и полумарафон, выделять сезон и серию. Сохранять место и время в возрастной группе, включая данные лидера, когда источник их предоставляет.
- Обеспечить трассировку до протокола. Не начислять очки за место как за обычную лыжную гонку для дистанций серии RL. Включение RL ÷ 7 зависит от решения методологов.
- Применять общий контракт источников и постановку в очередь из спеки «ПроБЕГ — второй источник и общий конвейер». Проверять данные до записи, сохранять происхождение и предыдущие корректные результаты при ошибке.
- По мере готовности расчёта дисциплины публиковать согласованную версию рейтинга. Для дисциплин без рабочего расчёта отражать факт импорта отдельно от публикации, без подмены бегового рейтинга.

## Тестирование и приёмка

- [ ] Фикстуры марафона и полумарафона, а также протокола без лидера группы. Данные относятся к правильному сезону.
- [ ] Сквозной сценарий через API и воркер на временной PostgreSQL. Подменяется внешний ответ обезличенной фикстурой. Проверить повторный импорт и сохранение опубликованных данных при ошибке по образцу пилота #27.
- [ ] Перед включением источника сверить один доступный живой старт на отдельном стенде с официальным протоколом. Проверить дистанции, число строк и контрольные значения. CI работает офлайн.

## За рамками

Общий редизайн админки, разработка формул рейтинга и включение других движков за рамками указанного источника.
