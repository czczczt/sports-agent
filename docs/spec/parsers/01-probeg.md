# ПроБЕГ — второй источник и общий конвейер

## Проблема

Есть разведка HTML и отдельный пробный скрипт. Админ не может провести старт ПроБЕГ через путь пилота #27.

## Решение

Выделить общий путь запуска и подключить ПроБЕГ как второй источник, сохранив поведение RussiaRunning.

## Пользовательские истории

1. Как администратор, я хочу запускать сбор и видеть статус, чтобы обрабатывать старты без отдельных скриптов.
2. Как модератор, я хочу видеть источник и неоднозначные совпадения, чтобы подтверждать только корректные привязки.
3. Как пользователь рейтинга, я хочу видеть согласованные результаты, чтобы сбой источника не менял мой балл.
4. Как разработчик, я хочу воспроизвести разбор на сохранённом образце, чтобы проверять изменения без сети.

## Решения по реализации

- Перевести существующий API запуска с ограничения на RussiaRunning на разрешённый реестр источников. Сохранить совместимость запроса с event_code и ответа по run_id.
- Подключить SourceAdapter по §6.1. Сгруппировать карточку события и дистанции, отличать ID события, дистанции и ссылки на профиль. Сохранять стабильность идентификаторов при повторной загрузке.
- Для дубля одного старта у агрегатора и первоисточника проверять признаки совпадения, отдавать предпочтение подтверждённому первоисточнику. Неоднозначность передавать в модерацию без двойных баллов.
- Использовать общий статус запуска, краткие ошибки, повтор временных сбоев, лимит домена по ТЗ, защиту публикации и раздельные блокировки источников. Сериализовать публикацию бегового рейтинга при одновременных запусках разных источников.
- Проверять данные до записи, сохранять происхождение и предыдущие корректные результаты при ошибке.
- По мере готовности расчёта дисциплины публиковать согласованную версию рейтинга. Для дисциплин без рабочего расчёта отражать факт импорта отдельно от публикации, без подмены бегового рейтинга.

## Тестирование и приёмка

- [ ] ПроБЕГ и RussiaRunning проходят через один HTTP-интерфейс и воркер. Параллельные запуски разных источников сохраняют оба протокола и дают согласованный рейтинг.
- [ ] В фикстуре есть несколько дистанций, строки с ссылкой на профиль и без неё, а также дубль старта у первоисточника. Проверить отсутствие двойного начисления.
- [ ] Сквозной сценарий через API и воркер на временной PostgreSQL. Подменяется внешний ответ обезличенной фикстурой. Проверить повторный импорт и сохранение опубликованных данных при ошибке по образцу пилота #27.
- [ ] Перед включением источника сверить один доступный живой старт на отдельном стенде с официальным протоколом. Проверить дистанции, число строк и контрольные значения. CI работает офлайн.

## За рамками

Общий редизайн админки, разработка формул рейтинга и включение других движков за рамками указанного источника.
