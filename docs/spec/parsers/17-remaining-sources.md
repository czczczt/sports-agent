# Разведка источников — DustyDumbbells, Rustriathlon, Triathlet и Забег.РФ

## Проблема

Для части источников ещё нет подтверждённых образцов протоколов или матрицы хронометристов.

## Решение

Для каждого источника зафиксировать публичный путь до финального протокола и подготовить отдельное решение о подключении.

## Пользовательские истории

1. Как администратор, я хочу видеть проверенный путь до протокола или явную причину недоступности, чтобы выбрать способ импорта.
2. Как модератор, я хочу видеть источник и неоднозначные совпадения, чтобы подтверждать только корректные привязки.
3. Как пользователь рейтинга, я хочу видеть согласованные результаты, чтобы сбой источника не менял мой балл.
4. Как разработчик, я хочу воспроизвести разбор на сохранённом образце, чтобы проверять изменения без сети.

## Решения по реализации

- Проверить зачётные дисциплины DustyDumbbells, Rustriathlon и Triathlet. Для Забег.РФ составить карту город → выпуск → хронометрист → движок, переиспользовать RR и другие подтверждённые адаптеры.
- Для каждого движка указать доступные поля, устойчивые ID, пагинацию, доступ со стенда, подходящий режим и примеры. Площадки с одним движком группировать.
- Если публичного протокола нет, зафиксировать ручной путь и уточнение, которое нужно от организатора.

## За рамками

Запуск массового сбора и самостоятельное изменение рейтинга. Если подтверждён новый движок, его интеграция оформляется отдельно.
