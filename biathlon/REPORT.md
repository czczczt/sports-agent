# Биатлон РФ: разведка источников и прототип парсера

Дата: 2026-10-16. Сезон в выборке: 2025/26.

## 1. Источники

| Источник | Что там | Формат | Архив | Вывод |
|---|---|---|---|---|
| **biathlonrus.com** (СБР) | Календарь всех российских стартов: Кубок и чемпионат России, первенства, межрегиональные, юношеские, летние (роллеры, кросс) | Обычный HTML (Bitrix), протоколы в **PDF** | Сезоны примерно с 2015/16 по 2026/27; самые полные — с 2019/20 | **Основной источник** |
| biathlon-results.ru | Онлайн-результаты во время гонки | Пустая страница вне сезона, архива нет | Нет | Не годится как архив. В Swagger видны только POST-эндпоинты `/Refresh/*` для загрузки данных хронометражем; **трогать их нельзя** |
| base.biathlonrus.com | Справочник спортсменов, тренеров, судей | **CSV** (`/files/lists/Athlete.CSV`), cp1251, `;` | Текущий срез | **Справочник для сопоставления спортсменов** |
| IBU datacenter | Международные старты | API | — | Россиян там нет с 2022 года, не нужен |

### Как устроен biathlonrus.com
```
/sorevnovaniya/rossiyskie/all/<сезон>/                → список соревнований сезона
  /sorevnovaniya/rossiyskie/<тип>/<сезон_N>/<slug>/   → страница соревнования
    /sorevnovaniya/races/<id>/                        → страница гонки
      /upload/iblock/.../<дата>_<пол>_<дисциплина>_RS.pdf  → итоговый протокол
```
Файлы на странице гонки: «Стартовый протокол» (SL), «Итоговый протокол» (RS), «Аналитика гонки» (RA), «Аналитика стрельбы» (SA), «Итоговый протокол Альфа-Банк Кубка России» (зачёт кубка).
В старых сезонах имена файлов — хеши, поэтому тип файла определяем **по подписи ссылки**, а не по имени.

### Протоколы
- PDF **текстовые, не сканы**, сделаны программой хронометража **WSRP**, поэтому `pdfplumber` извлекает текст без OCR.
- В подвале есть **контрольные суммы**: ВСЕГО / ФИН / НС / НФ / ДСКВ / КРУГ. Это готовая самопроверка парсера.
- В протоколах Кубка и чемпионата России есть столбец **«Очки»** (150, 146, 143, …). Это официальные очки, по ним можно сверять нашу формулу.

## 2. Прототип

| Файл | Что делает |
|---|---|
| `schema.py` | Pydantic-модели `Race` и `Result` (черновик единой схемы) |
| `sbr_crawler.py` | Обход сезон → соревнования → гонки → PDF; кеш в `data/raw`, пауза 1 с между запросами |
| `parse_protocol.py` | PDF → записи; разбирает статусы (FIN/DNS/DNF/DSQ/LAP); нормализует артефакты текста; проверки по подвалу и по полям |
| `sbr_base.py` | База спортсменов СБР: привязка к коду СБР, проверка OCR, запасное восстановление ФИО, оценка точности восстановления |
| `ocr_names.py` | OCR ячеек ФИО, нарисованных картинкой (Tesseract, модель в `tessdata/`) |
| `eval_ocr.py` | Оценка точности OCR на строках с текстовым слоем → `data/processed/ocr_eval.json` |
| `run.py` | Запуск: `python run.py --season 2025-2026 --filter kubok-rossii --max-races 40 --tag cup` |
| `summarize.py` | Сводка качества по всем прогонам → `data/processed/summary.txt` |

Стек: `requests` + `BeautifulSoup/lxml` для HTML, `pdfplumber` для PDF, Tesseract 5 для ФИО-картинок. Selenium **не нужен**: сайт не требует JS.

Установка: `pip install -r requirements.txt`, плюс Tesseract 5 в системе и `tessdata/rus.traineddata` (скачать с github.com/tesseract-ocr/tessdata, ~20 МБ).

### Проверки качества (встроены в парсер)
1. Число записей по статусам совпадает с подвалом (ФИН, НС, НФ, ДСКВ, КРУГ, ВСЕГО).
2. Места идут по порядку и начинаются с 1.
3. У каждого финишёра есть время, и время растёт вместе с местом.
4. Число рубежей одинаково у всех финишёров гонки, а сумма промахов совпадает со столбцом «Сум».

> Урок первого прогона: проверка 1 сама по себе **не ловит ошибки в полях**. Все строки были найдены, но время извлекалось только у 50% финишёров. Проверки 3–4 обязательны.

v1 — первый прогон, v2 — после доработки под юношеские вёрстки (см. раздел 4). Всего 5241 запись.
- На Кубке и чемпионате **все личные гонки** проходят проверки: спринт, преследование, индивидуальная, масстарт, суперспринт, суперпреследование.
- Не проходят: **эстафеты** (командный формат, пока не поддержан) и 6 личных гонок:
  - в 3 гонках недобор строк (часть строк не извлекается совсем);
  - в 3 гонках стрельба не сходится **в самом протоколе**: например, промахи 1+2, а в «Сум» стоит 5. Скорее всего, это штраф решением жюри. Парсер прав, что помечает такие строки.
- У 23 из 80 юношеских гонок **нет итогового протокола** на сайте вообще.

### ФИО, нарисованные картинками: OCR + сверка с базой СБР
В части PDF (сделанных через doPDF) ФИО и иногда код региона **нарисованы картинками**, текста там нет: 170 строк в юношеской выборке. В «Аналитике гонки» то же самое.

**Как распознаём** (`ocr_names.py`). Находим строку по стартовому номеру, вырезаем ячейку между номером и датой рождения, рендерим её в 400 dpi и распознаём Tesseract 5 (`rus`, режим одной строки `--psm 7`). Модель `rus.traineddata` лежит в `tessdata/` проекта. Затем сверяем с базой СБР по ФИО + дате рождения.

**Точность OCR** (`eval_ocr.py`). Берём строки, где ФИО есть **текстом**, распознаём ту же ячейку как картинку и сравниваем с текстом. Выборка: 347 ячеек из 45 случайных протоколов, без эстафет.

| Поле | Точность |
|---|---|
| Фамилия | **100%** |
| Имя | **100%** |
| Фамилия + имя (ключ для сопоставления) | **100%** |
| Отчество | 98,6% |
| Регион | 99,1% |
| Вся ячейка целиком | 97,7% |
| CER (доля ошибок по символам) | 0,17% |

Почти все ошибки — **обрезанное окончание отчества** («Александровн», «Павлова» вместо «Павловна»). Длинное ФИО в PDF визуально обрезается шириной колонки, поэтому в текстовом слое оно полное, а на картинке нет. Это ограничение источника, а не OCR. У строк, подтверждённых базой, отчество берётся из базы.
«Ошибки» по региону — это строки, где регион в PDF тоже картинкой: OCR его прочитал, а в текстовом слое пусто. Так что здесь OCR прав.

**Результат на 170 строках-картинках:**

| Итог | Строк | `name_source` |
|---|---|---|
| Распознано и **подтверждено** базой СБР (ФИО + ДР) | 113 | `ocr+sbr` |
| Распознано, человека нет в базе (проверить нечем) | 55 | `ocr` |
| Распознано, но **конфликт** с базой | 2 | `ocr_unverified` |
| Не распознано | 0 | — |

Оба конфликта поучительные:
- **ВАСИЛЬЦОВА Анна** против базы «Васильцова Диана» с той же датой рождения. Это **близнецы**: обе есть в текстовом протоколе спринта того же турнира, а в базе только Диана. Прав OCR. Восстановление по дате рождения здесь ошиблось бы.
- «ПНА лУ слав н сПосВиИч» — мусор OCR, проверка его поймала.

### Восстановление ФИО по базе СБР (запасной путь)
Если OCR не справился, ищем в базе человека с той же датой рождения, полом и регионом и принимаем только однозначный ответ. После появления OCR этот путь в текущей выборке не понадобился, но метод и его оценка остаются.

**Оценка точности.** Берём строки, где ФИО известно и найден код СБР, прячем ФИО, восстанавливаем и сравниваем с настоящим:

| Выборка | Ключ | Доля восстановленных (coverage) | Точность (precision) |
|---|---|---|---|
| Кубок России | ДР + пол + регион | 81,6% | **100%** (1119/1119) |
| Кубок России | ДР + пол | 88,6% | 100% |
| Чемпионат России | ДР + пол + регион | 79,7% | **100%** (1191/1191) |
| Юношеские | ДР + пол + регион | 65,7% | **99,6%** (689/692) |
| Юношеские | ДР + пол | 48,3% | 98,6% |

До OCR этим путём восстанавливалось 99 из 170 строк-картинок.
- ⚠️ **Близнецы** (одна дата рождения, один регион) ломают этот метод: если в базе только один из них, ответ будет однозначным, но неверным. Поэтому OCR — основной путь, а база — проверка.
- На Кубке ключ без региона даёт **больше** восстановлений: регион в протоколе и в базе иногда расходится (двойной зачёт, переход в другой регион). У юношей наоборот: ровесников много, и без региона кандидат перестаёт быть однозначным.
- ⚠️ Оценка оптимистична. Её можно посчитать только на людях, которые есть в базе. Если настоящего спортсмена в базе нет, а его однофамилец по ДР + полу + региону есть, это даст ложное совпадение. У юношей в базе находится только ~50% спортсменов (у Кубка — 96%).

**Привязка к коду СБР** (по ФИО + ДР): Кубок 1371 / 1426 (96%), чемпионат 1495 / 1559 (96%), юношеские 1167 / 2256 (52%, с учётом OCR). Младших юношей и любителей в базе мало.

## 4. Подводные камни (подтверждены на данных)

**Источник**
- biathlon-results.ru показывает только текущие гонки; архив — только на biathlonrus.com.
- Список соревнований идёт по алфавиту, поэтому выборка «первые N» — это не случайная выборка. Первые 80 гонок оказались сплошь межрегиональными юношескими.
- Помимо обычных гонок есть летние: «Роллеры - …», «Кросс - …». Нужно решить, входят ли они в рейтинг.
- Помимо «Итогового протокола» бывает «Итоговый протокол Альфа-Банк Кубка России» (зачёт кубка). Брать нужно именно первый.

**Вёрстка протоколов**
- **Шапке таблицы доверять нельзя.** В индивидуальной гонке шапка не показывает очки и разряд, хотя в строках они есть. У чемпионата в строке две колонки очков (`150 80`), у масстарта шапка «Вып. разряд». Решение: якорем служит итоговое время, а не шапка.
- **Обогнанные на круг** (КРУГ) получают место и **очки**, но вместо времени у них стоит «КРУГ». В подвале они не входят в ФИН.
- **Протоколы делают как минимум три программы** с разной вёрсткой: WSRP (Кубок, чемпионат, часть юношеских), Ski123 / SIWIDATA (межрегиональные), плюс разные PDF-принтеры (doPDF, Microsoft Print to PDF, wPDF).

| Проблема | Где | Как решено |
|---|---|---|
| ФИО / регион нарисованы картинкой | WSRP через doPDF | OCR ячейки (Tesseract rus) + сверка с базой СБР |
| Разрядка: `2 р а з р я д` | Ski123 (шрифт с межбуквенным интервалом) | Сжатие одиночных букв в слово (`normalize_line`). Подбор `x_tolerance` не помогает: при 4 получается «р а зр я д» |
| Склейки: `Александровна20.07.2012`, `15ГАЛИМЖАНОВ` | Ski123 | Вставка пробела перед датой и между цифрой и фамилией КАПСОМ |
| Нет кода региона или вместо него код клуба (АНО, СИБ, ДВН…) | юношеские | Регион необязателен |
| «Не стартовало / Не финишировало» вместо «…ли» | Ski123 | Расширен словарь секций |
| Прочерки вместо нулей в подвале (`27 27 - - - -`) | Ski123 | `-` = 0 |
| Год рождения вместо даты, время с запятой (`19:15,7`), разряд **после** ходового времени | летние (роллеры, кросс) | `birth_year`, поиск ходового времени в любом месте |
| В шапке «Л C Л C», а в данных 3 рубежа | индивидуальная 13–14 лет | Число рубежей берётся из данных, а не из шапки |
| Разряд записан голой цифрой («1») и уезжает в промахи | юниоры | Лишняя ведущая цифра переносится в разряд, если без неё сходится сумма |
- **Эстафеты** — отдельный формат: этапы `2 - 1 к`, стрельба вида `0+1` (промахи + дозарядки).
- **Очки бывают дробными и двойными:** `-/65`, `64/64`, `56,5/-`. Видимо, это деление очков между двумя регионами у спортсменов с двойным зачётом («Санкт-Петербург - Вологодская область»).

**Специфика биатлона**
- В индивидуальной гонке на 15 км штраф **45 с** за промах, а не 1 мин: короткая индивидуальная гонка. Формулу нельзя зашивать константой.
- Разряды записаны десятком способов: `1 разряд`, `1р`, `1 юн`, `1 юношеский`, `1 юр`, `б/р`, `КМС`, `МС`, `МСМК`. Нужен словарь.

**Спортсмены**
- В фамилиях встречается **Ё** (44 записи): ЕРЁМИН и ЕРЕМИН нужно склеивать.
- В CSV базы СБР столбец «Фамилия Англ» на самом деле содержит **отчество**: колонки сдвинуты.
- Код СБР в CSV записан как Excel-формула `="112010200800"`.
- База СБР — это 4569 действующих спортсменов федерации 1977–2014 годов рождения. **Любителей в ней нет.**
- Коды регионов в протоколах и в базе совпадают (МОС — Московская область, МСК — Москва). Это хорошо для сопоставления.

**Данные и право**
- ФИО + дата рождения — **персональные данные** (152-ФЗ). `data/raw` и `data/processed` не выкладывать в публичный репозиторий.

## 5. Следующие шаги
1. Разметить вручную 20–30 протоколов как эталон (dev/test). Проверки по подвалу уже дают «бесплатную» частичную разметку.
2. Строки `ocr_unverified` и `ocr` (без подтверждения базой) показывать в отчёте для ручной проверки. Проверить OCR на других сезонах.
3. Добавить эстафеты (или явно исключить их из личного рейтинга).
4. Нормализация: словари разрядов и регионов, Ё→Е.
5. Выгрузить столбец «Очки» Кубка России и восстановить по нему таблицу «место → очки». Это первая проверка будущей формулы.
6. Прогнать весь сезон 2025/26 (не только первые 80 гонок) и сезоны 2019/20–2024/25, оценить, как меняется вёрстка по годам.
